# VIP Robot Project — Construction Robotics for Engineering Education

## Overview

The VIP Robot Project is a construction robotics initiative developing a suite of 
robotic systems designed to teach Construction Engineering and Management (CEM) 
students how robotics is applied on real-world construction jobsites. The project 
bridges the gap between academic instruction and industry practice by giving 
students hands-on exposure to the robotic technologies increasingly used in 
modern construction.

The project is developed in **Unity**, enabling the robots and simulated jobsite 
environments to be deployed across **virtual reality (VR) and mixed reality (MR) 
devices**. This allows students to interact with and learn from these robotic 
systems in an immersive, device-flexible environment rather than being limited 
to a single hardware platform.

## Purpose

Construction robotics is rapidly transforming jobsite operations — from automated 
layout and surveying to material handling and safety monitoring. However, most 
CEM curricula do not expose students to these tools before they enter the 
workforce. This project addresses that gap by building functional robot 
prototypes and accompanying immersive learning modules that simulate actual 
jobsite use cases, helping students develop practical, job-ready robotics 
literacy through VR/MR-based interaction.
